- Chrome 157 无界面浏览器，**69 项检查通过、0 失败、0 控制台／运行时错误**。

完整记录、受测文件 SHA-256 和逐项结果见 [browser-checks.json](browser-checks.json)。测试通过真实 DOM 控件及浏览器输入完成，没有直接更改应用内部状态以制造通过结果；测试脚本为临时检查工具，未作为产品代码交付。

| 范围 | 本次检查 |
| --- | --- |
| 明暗主题 | 首次默认跟随系统、系统实时变化、手动覆盖与恢复跟随、刷新保留偏好、存储不可用时仍可切换；切换不改变审核状态或确认窗口输入 |

| 取消与未知结果 | 运行中停止保留 UNKNOWN；启动前取消后使用新尝试；签名未知、提交未知和取消后发现签名只核对原结果 |
